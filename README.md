# Python & Pandas Data Analysis - Assignment 1

This repository contains solutions for **Assignment 1**, focusing on data manipulation, selection, and preparation using Python and Pandas.

## 📌 Contents & Topics Covered

- **Q1. Student Performance DataFrame: Construction and Analysis**
  - DataFrame creation, summary statistics, filtering, and performance metrics.
- **Q2. Advanced Row and Column Selection Using \iloc\ and \loc\**
  - Index-based vs. label-based indexing, conditional masking, and subset slicing.
- **Q3. Series vs. DataFrame: Feature Selection and Validation**
  - Structural differences, dimensions, handling single vs. multiple features.
- **Q4. End-to-End Data Preparation Challenge**
  - Data cleaning, missing value handling, column transformation, and pipeline preparation.
